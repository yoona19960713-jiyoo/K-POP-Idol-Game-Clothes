衣櫥間

左邊是她目前的造型。下面點任一套「穿上」就會換過來;「生圖底模」是產生提示詞時要一起附給 GPT 的定案立繪。

底模請用遊戲表情組那張定案平常立繪(灰底、白 T、平常表情)。練習服和日常服在遊戲裡會疊上她的表情,底圖不同的話臉會對不上。

設定

Gemini API 金鑰

金鑰只存在這台裝置,不會上傳到任何地方。手機和電腦要各自貼一次。

怎麼取得金鑰?
  1. 用 Google 帳號登入 aistudio.google.com
  2. 左側點「Get API key」
  3. 按「Create API key」,複製那串文字
  4. 貼到上面的框,按儲存,再按測試連線

免費層級有每分鐘與每日次數上限,每日額度約在台灣時間下午三、四點重置。免費層級送出的內容可能被 Google 用來改進產品,請不要放私人照片。

雲端同步

網頁版和手機用同一個帳號登入,資料會自動雙向同步。需要你自己的 Firebase 專案(免費方案即可)。

備份與同步

資料存在這台裝置。要在手機和電腦之間同步,在一邊匯出備份,另一邊匯入即可;同編號的單品會保留較新的版本。
