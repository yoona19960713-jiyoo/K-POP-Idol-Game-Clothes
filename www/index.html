衣帽間素材工坊

總庫管理單品設計;五位成員各自的頁面負責把單品適配到她身上、試穿組裝。

還沒設定 Gemini API 金鑰,分析功能無法使用。

標準底模

總庫的單品都在這張底模上生成,它也是「自動適配」的來源:程式會依它和每位成員的關鍵點,把單品變形到成員身上。

新增素材

點這裡選照片,或把圖片拖進來
可一次放多張同一套穿搭的不同角度。臉部不會被分析,只看衣物。

分析結果

確認或修改後收入資料庫。取消勾選的單品不會收入。

批次模式

一行寫一套造型的描述,按開始後會一套接一套自動設計、拆成單品,直接收進資料庫,不用逐件確認。要拆出的大項沿用上方「新增素材」的設定。

    資料庫

    底模

    生圖用底模:綠色背景、白上衣、白短褲、白襪,姿勢與取景跟標準底模一致,附在這位成員的專屬提示詞上。組裝用身體層:衣櫥間實際疊衣服的身體,沒有另外上傳就沿用生圖用底模。兩張的姿勢與取景必須完全相同。

    專屬版

    自動變形不自然時,把這段提示詞連同的生圖用底模一起交給 GPT,切好圖後上傳。直接上傳 GPT 生成的「只剩單品、背景純色」原圖,工坊會自動去背,不要裁切。上傳專屬版後就不再自動變形,但仍可用上面的滑桿微調。

    先點下面的點名稱,再點圖上的位置,放好會自動跳到下一個。已放好的點可以直接拖曳微調。左右指畫面上的左右。實心點是已標記,空心點是預設位置。

    設定

    Gemini API 金鑰

    金鑰只存在這台裝置,不會上傳到任何地方。手機和電腦要各自貼一次。

    怎麼取得金鑰?
    1. 用 Google 帳號登入 aistudio.google.com
    2. 左側點「Get API key」
    3. 按「Create API key」,複製那串文字
    4. 貼到上面的框,按儲存,再按測試連線

    免費層級有每分鐘與每日次數上限,每日額度約在台灣時間下午三、四點重置。免費層級送出的內容可能被 Google 用來改進產品,請不要放私人照片。

    備份與同步

    資料存在這台裝置。要在手機和電腦之間同步,在一邊匯出備份,另一邊匯入即可;同編號的單品會保留較新的版本。
